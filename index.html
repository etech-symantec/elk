ELK 리소스 계산기 (CPU / MEM / Disk) 일일 로그 크기와 보관 기간을 입력하면 ODIN-I BASIC 사이즈 가이드를 기반으로 필요한 CPU·메모리·디스크를 추정합니다.

※ 일일 로그 크기는 gz로 압축된 상태의 파일 크기를 기준으로 입력합니다. ES 색인에 필요한 원본(비압축) 로그량은 아래 "gz 압축률" 옵션으로 역산합니다.
ES가 원본 로그를 색인할 때 역색인(inverted index), doc values, 저장 필드, 세그먼트 병합 여유공간, 메타데이터 등이 추가되면서 원본 로그 대비 커지는 비율입니다. 통상 1.3~1.5배를 기준으로 산정합니다.
gz 압축 후 크기가 원본(비압축) 로그의 몇 %인지입니다. 기본 10%(=10:1 압축)는 일반 텍스트 로그 기준값이며, ES 색인 대상 원본 크기 추정에 사용됩니다.
